# v1.7.43 — 补齐 DSH 0.1.7 侧栏兼容

修复 [#192 的追加反馈](https://github.com/Han-1413141/dsh-cost-meter/issues/192#issuecomment-5871206768)：升级 v1.7.42 后，dsh-context 的入口仍被挤到侧栏外。

上一版遗漏了 DSH 0.1.7 插槽中的 `display: contents` 包装层，分行规则没有作用于真正的 flex 容器。本版补上该结构，使费用区和其他插件入口正确分行，并保留旧宿主、收起侧栏及动态隐藏和卸载时的布局。

浏览器回归已加入遗漏的宿主结构：v1.7.42 复现原问题，修复版通过 48 种布局、20 次动态切换及 598 项断言。

## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.43/install.ps1 | iex
```

升级后重启 DSH；Web 版同时刷新页面。
