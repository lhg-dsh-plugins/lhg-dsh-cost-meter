## v1.7.14 更新

- 修复千问 Credits 费率行刚添加就消失：三项填齐才自动保存，刷新后保留；带点号和连字符的模型名覆盖可正确折算。（#103）
- 未知模型点击移除后保持隐藏，可手动恢复；移除映射与清空费率不再被深合并恢复，用量记录保留。（#104）
- 接收隔离 LLM 服务中的子代理、后台调用 usage。子会话独立记账；没有会话 ID 的调用进入总计。未向宿主报告 usage 的外部请求仍无法统计。（#101）
- 整合社区 PR #102 / #105：Antigravity 分组友好名称、长标签布局、标准/紧凑两列侧边栏切换及 daily 双语标签。
- DSH 凭据和路径包改由宿主复用，修复依赖预检阻断；补充当前宿主的精确兼容记录。（#106）

验证：Asia/Shanghai 与 UTC 全量回归；DSH 0.1.2-rc.1 / 0.1.3-alpha.2 安装、启动、共享宿主模块、隔离合成 usage 和卸载通过；alpha.2 实际 Web 页面完成保存、移除/恢复、刷新与侧栏检查。alpha.1 官方安装包不可获取，保留 unknown；Desktop 整壳与真实记忆插件外部账单未测。[完整兼容记录](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.14/docs/host-compatibility-v1.7.14.md)

DSH STORE 将对新固定 commit 重新审核，发布插件不等于商店已恢复上架。

## 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.14
```

Windows 一键安装也可使用：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.14/install.ps1 | iex
```

升级后重启 DSH Web / Desktop，再刷新页面。
