## v1.8.14

- Fixed [#237](https://github.com/Han-1413141/dsh-cost-meter/issues/237) through [#238](https://github.com/Han-1413141/dsh-cost-meter/pull/238): a recycled owner PID no longer permanently pins a stale ledger lock and prevents the plugin from activating.
- Owner filenames remain compatible. New owner records identify the process by Linux boot ID/PID namespace/start ticks or Windows native creation time. Legacy empty owner files recover when they demonstrably predate the named process's birth, with a timestamp margin. Matching live owners and unknown/incomplete identities remain protected.
- Recovery removes only the identified stale owner and empty lock directory. The ledger and recorded amounts are retained without repricing. Added real live-holder, PID-reuse, unchanged-ledger and real Cordis cold-start regressions; full local regression, eight-process concurrency and PR CI passed on the covered Windows/Linux environments.
- Update and restart an already failed DSH host once. The plugin recovers proven stale locks before activation; DSH's loader/HMR retry policy is unchanged. See the [bilingual recovery guide](../ledger-lock-recovery.md).

- 通过 [#238](https://github.com/Han-1413141/dsh-cost-meter/pull/238) 修复 [#237](https://github.com/Han-1413141/dsh-cost-meter/issues/237)：旧锁的 PID 被系统复用后，不再长期占锁并阻止插件挂载。

- 已失败的 DSH 宿主更新后重启一次即可使用修复。插件在挂载前恢复已确认失效的锁；DSH 加载器自身的重试策略保持原有行为。见[双语账本锁恢复说明](../ledger-lock-recovery.md)。

## Upgrade / 升级

Web Profile:

```powershell
dsh plugin --profile web add github:Han-1413141/dsh-cost-meter#v1.8.14
```

Restart `dsh web`, then reload the page. Desktop users should update the application's `desktop` Profile with its own CLI, then fully exit the application (including its tray process) and reopen it. See the [Desktop installation guide](../install-troubleshooting.md#desktop-安装与更新).

Web 用户更新后重启 `dsh web` 并刷新页面。桌面端使用应用内置 CLI 更新 `desktop` Profile，然后完全退出应用（包括托盘）再打开。
