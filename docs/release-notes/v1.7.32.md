## v1.7.32 — Custom balance display currency

### English

Resolves #162: each custom USD balance now has an optional **Convert USD balance to display currency** switch under **Settings → Cost → Quota**. It defaults to off and persists independently for each entry.

A $54.3792 balance with CNY display, a 7.2 exchange rate and two decimal places displays as **¥391.53**. Remaining balance, spend and API/manual limits convert together in sidebar rows/cards, settings and tooltips. Source snapshots, ledger values and progress percentages stay unchanged; toggling does not trigger a balance request.

Keep **Source currency** set to the endpoint's real currency and enter manual limits in that currency. The existing exchange rate is USD-to-display only: CNY/EUR source balances and Credits retain their units, and Alibaba Cloud uses the API's actual currency. Turning the switch off restores the source display.

### 中文

解决 #162：在**设置 → 费用 → 额度**展开自定义余额，开启**按显示币种折算（USD 余额）**。开关默认关闭，每条配置独立保存，支持重启和旧单条配置。

例如美元余额 54.3792，显示 CNY、汇率 7.2、两位小数时显示 **¥391.53**。余额、已用金额和上限一起折算，覆盖侧栏、设置页和悬停明细；原始数据、账本和进度比例保持不变。切换不会额外查询余额。

“余额原币种”应保留端点实际币种，手动上限也按原币种输入。非美元余额和积分不使用美元汇率；阿里云以接口返回币种为准。关闭开关即恢复原币种显示。
