## v1.7.35 — Bailian quotas, gzip responses and model names

### English

- **#170:** Hover over a model label in the cost, token, cache-hit or value charts to see its full provider/model name. The existing chart layout is preserved.
- **#171:** Adds **Bailian CLI** as the third Qwen quota source alongside Local estimate and Official CLI. Token Plan and Coding Plan queries run in parallel. The reviewed integration fixes the contributor's field mapping and ratio conversion against official CLI source: `0.5` means **50%**, and Token Plan uses flat fields. A malformed or failed source no longer hides a valid subscription from the other command. Credentials stay in the CLI; account totals never enter the DSH ledger. See [setup and output semantics](../qwen-cli-quota.md).
- **#172 / #173:** Accepts gzip-compressed JSON even when the CDN omits `Content-Encoding`. Both compressed input and decoded output remain bounded. Invalid response bodies are not included in error messages.
- **#174:** GLM quota queries use the same bounded gzip/JSON reader. Failed queries now show every candidate's HTTP status and network, JSON or usage failure category in request order. The host debug logger receives the same safe records. A final legacy-endpoint 404 no longer hides earlier monitor failures. HTTP error responses are released and cancellation stops fallback.

The precise cause of #174 inside the reporter's DSH process is **not yet confirmed**. This release fixes the reproducible response-decoding and error-reporting paths; the issue remains open for the reporter's in-host results. It does not change the host's proxy, TLS or global dispatcher configuration.

### 中文

- **#170：**费用排行、Token 消耗、缓存命中率和性价比图的模型标签支持悬停查看完整 provider/model 名称，保持现有布局。
- **#171：**千问额度来源新增**百炼 CLI**，与本地估算、千问官方 CLI 并列。并行查询 Token Plan 与 Coding Plan；按官方源码修正贡献中的字段映射及比例换算，`0.5` 正确显示为 **50%**，Token Plan 使用独立的扁平字段。一方查询或格式失败时仍显示另一方的有效额度。凭据由 CLI 保管，账号总量不写入 DSH 账本。详见[配置说明](../qwen-cli-quota.md)。
- **#172 / #173：**兼容 CDN 缺少 `Content-Encoding` 的 gzip JSON，压缩前后均保持大小限制，解析错误不回显响应正文。
- **#174：**GLM 额度查询接入相同的有界 gzip/JSON 读取。失败时按顺序展示每个候选的 HTTP 状态与网络、JSON、用量解析错误类别，宿主调试日志记录相同的脱敏信息；链尾旧接口的 404 不再覆盖前面的 monitor 失败。及时释放 HTTP 错误响应，取消请求后停止回退。

#174 在报告者 DSH 进程内的具体原因**尚未确认**。本版修复已复现的响应解析和错误展示路径，该 Issue 保持打开，等待报告者的宿主内复测结果；不改动宿主代理、TLS 或全局 dispatcher 配置。

### Upgrade / 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.35
```

Update other profiles that use the plugin, restart DSH and refresh the browser. / 同时更新其他已安装插件的 profile，重启 DSH 并刷新浏览器。

### GLM follow-up / GLM 复测

Refresh the GLM card once. If it still fails, report the displayed per-endpoint status/category and the DSH/Node versions in #174. `INVALID_JSON`, `RESPONSE_TOO_LARGE`, TLS/network codes, authorization status and numeric API codes identify different failure stages. Do not post API keys, credential files, request headers, response bodies or proxy credentials.

手动刷新一次 GLM 卡片；如仍失败，请在 #174 提供显示的逐端点状态/类别以及 DSH、Node 版本。`INVALID_JSON`、`RESPONSE_TOO_LARGE`、TLS/网络错误码、认证状态及数字业务码分别对应不同失败阶段。不要粘贴 API Key、凭据文件、请求头、响应体或代理密码。

### Validation / 验证

The full regression suite covers the new CLI source with source-shaped fixtures and real child processes, plus actual HTTP bare-gzip responses, decompression limits, candidate fallback, error redaction and cancellation. The rebuilt client remains below the 256 KiB single-file limit. No live paid Bailian or GLM subscription was queried.

完整回归包含官方字段形态的百炼测试数据与真实子进程、真实 HTTP 裸 gzip 响应、解压上限、候选回退、错误脱敏及取消请求。客户端重新构建后仍低于 256 KiB 单文件上限；未查询真实付费百炼或 GLM 订阅。
