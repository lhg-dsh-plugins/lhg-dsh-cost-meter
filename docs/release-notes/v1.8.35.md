## v1.8.35 — 网页抓取计费与 DSH alpha.5 适配

- 支持 DeepSeek Search／Fetch 独立 API：成功且有结果的请求 ¥0.005／次；次数费单独显示，计入会话、每日费用与预算，保存当时汇率，不增加 Token、不套模型倍率或峰谷折扣。
- 网页抓取独立分类；本地 HTTP 抓取不增加官方请求费，失败和空结果不收费。内置搜索免费期不猜测结束日期。[计费范围](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.35/docs/web-request-fees.md)

- 验证 DSH 0.2.1-alpha.5 的真实安装、Web 启动、计费、RPC、原生搜索与上下文联动；补充兼容性标记和预发布 peer 范围。
- 适配新宿主的旧会话离线修复命令：通过官方存储插件取得独占锁，在空临时目录初始化，保留原样备份、锁冲突拒绝写入和旧宿主支持。
- 日常计费逻辑、价格、历史金额和界面布局不变。v1.8.34 的日常功能可直接使用；在新宿主上使用离线修复命令需升级本版。
- 自动回归更新到 alpha.5，并按新网关调用身份及凭据优先级验证，保留旧宿主对照。

[验证说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.35/docs/dsh-alpha5-compatibility.md)。升级后完全重启 DSH。

### English

Adds official standalone Search/Fetch request fees at CNY 0.005 per successful nonempty response, separately from model tokens and with historical FX. Local HTTP fetching and empty/failed responses are not charged. Verifies DSH 0.2.1-alpha.5 and adapts offline session repair to the official persistence plugin while retaining locking, backups and older-host support. Existing model-token rates and historical amounts remain unchanged.
