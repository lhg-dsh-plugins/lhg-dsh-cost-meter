## v1.7.28 更新

- **#152 MiniMax 域名配置**：额度查询默认优先使用 `https://www.minimax.cn`，保留国际站和旧国内站回退。
- MiniMax Token Plan 卡片新增「查询域名（HTTPS）」。设置会随账本保存，更新插件后保留；填写后只访问该域名，清空恢复自动模式。MiniMax Key 会发送到所填域名，请使用可信地址。
- 修改域名会使旧缓存失效并取消旧请求，迟到结果不能覆盖新来源；并发刷新合并，失败遵守刷新间隔，手动刷新可立即重试。请求拒绝重定向并限制响应体。
- 配置校验、持久化、Host / 已构建 Client codec、双语交互及完整回归通过。未使用真实 MiniMax Key 验证账号额度。

完整用法见[查询域名说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.28/docs/minimax-quota-endpoint.md)。

## Upgrade / 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.28
```

或使用固定版本安装脚本：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.28/install.ps1 | iex
```

完全退出并重启 DSH，再刷新 Web UI。查询域名留空即可默认优先使用新国内站。

**English:** MiniMax quota queries now try `www.minimax.cn` first. A persistent HTTPS origin field supports a chosen official site or trusted compatible proxy. Explicit origins never fall back to another host; clear the field for automatic selection. Origin changes cancel old requests and invalidate cached quotas. Includes validation, persistence, shipped-client, bilingual UI and full regression coverage. Live account quotas were not tested.
