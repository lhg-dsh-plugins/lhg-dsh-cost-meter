# v1.7.15：千问渠道隔离与默认峰谷计价

- 修复 #108：千问 Token Plan Credits 保留 provider 维度。`qianwen-tokenplan` 订阅渠道计入，`qianwen` 按量渠道的同名模型不计入；支持其余文档列出的订阅别名，并遵守显式 API 分类。
