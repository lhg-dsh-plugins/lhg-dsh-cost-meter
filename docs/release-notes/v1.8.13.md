## v1.8.13

- Added the optional **Amount only below the composer (full split on hover)** switch from [#236](https://github.com/Han-1413141/dsh-cost-meter/pull/236). Open **Settings → Cost → Display** to enable it. It is off by default.
- The conversation cost line shows amounts only. Hover retains the complete cache-hit/input/cache/output line and per-model amounts. API costs and Plan equivalents remain separate; the include-Plan and include-subagents settings continue using recorded ledger amounts. Header badges and Cost details are unchanged.
- Fixed the contribution's missing full-line tooltip and added bilingual rendered-output regressions covering API/Plan split, combined totals, output-only sessions, subagent ledger precedence and unchanged header details. Configuration validation, strict RPC round trips and checkbox auto-save are covered. The complete local regression and all 12 PR CI jobs passed, including both supported client generations.
- All 532 Chinese and 532 English translations are preserved. The generated client is 261,976 bytes, below the 262,144-byte limit.

Thanks to **JanEickholt** for the contribution.

## Upgrade / 升级

Web Profile:

```powershell
dsh plugin --profile web add github:Han-1413141/dsh-cost-meter#v1.8.13
```

Restart `dsh web`, then reload the page. Desktop users should update the application's `desktop` Profile with its own CLI, then fully exit the application (including its tray process) and reopen it. See the [Desktop installation guide](../install-troubleshooting.md#desktop-安装与更新).

Web 用户更新后重启 `dsh web` 并刷新页面。桌面端使用应用内置 CLI 更新 `desktop` Profile，然后完全退出应用（包括托盘）再打开。
