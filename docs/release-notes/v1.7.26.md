## v1.7.26 更新

- **#146 千问官方 CLI 额度**：千问额度卡片新增官方 CLI 来源，可查询订阅 Credits、可选加量包及订阅到期时间；保留本地估算与原有配置。支持定时刷新、并发合并及超时处理，额度耗尽后仍显示使用情况。订阅到期时间不会被当作月度重置时间。
- **PR #145 Antigravity 分组筛选**：每个来源可独立开启「只显示 Gemini 额度」，全部被过滤时显示空状态。
- **PR #147 自定义积分余额**：新增 `CREDITS` 单位，保留小数并显示积分单位；积分不套用货币预算或美元消费换算。自定义余额支持本机回环 HTTP 端点，其他主机仍需 HTTPS。
- 保留 @Oct1AtJoe 的原始提交，感谢两项贡献。Windows / Linux 安装检查、完整回归、客户端构建一致性与 CodeQL 检查已通过；千问 CLI 通过真实子进程和模拟订阅数据验证，未使用真实订阅账号。

千问 CLI 的安装、登录与额度来源设置见 [使用说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.26/docs/qwen-cli-quota.md)。
