## v1.7.37 — Chinese public holidays use off-peak pricing

### English

DeepSeek calls on Chinese public holidays now use off-peak rates for the full Beijing calendar day. The default `peakHolidays` list covers the published 2026 Mid-Autumn and National Day dates; it can be edited under Settings → Cost → Peak pricing. Work-shift Saturdays and Sundays remain off-peak under [DeepSeek's pricing rule](https://api-docs.deepseek.com/quick_start/pricing/). The dates come from the [State Council's 2026 holiday schedule](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm). The period strip labels public holidays and skips price changes that cannot occur during the holiday.

On upgrade, the plugin recalculates affected DeepSeek history from complete session logs and updates session and daily totals. Records without complete matching logs keep their prior amounts rather than applying a guessed daily discount. Update all profiles that use the plugin, restart DSH, and refresh the browser.

### 中文

中国法定假日全天按北京日历日期使用 DeepSeek 谷价。`peakHolidays` 默认包含[国务院办公厅公布的 2026 年中秋、国庆日期](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，可在 设置 → 费用 → 峰谷计价 中编辑。调休上班的周六、周日仍按 [DeepSeek 官方规则](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)全天谷价。时段条单独标注假日，倒计时跳过假期内不会发生的价格切换。

升级后，插件会根据完整会话日志逐次修正受影响的 DeepSeek 历史费用，并同步会话与每日合计。缺失日志或日志用量与账本不一致的记录保留原金额，避免按日总量猜测峰谷折扣。请更新所有安装此插件的 profile，重启 DSH 并刷新浏览器。

### Upgrade / 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.37
```
