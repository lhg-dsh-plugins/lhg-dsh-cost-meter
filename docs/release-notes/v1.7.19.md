## v1.7.19 更新

### 可选简化侧栏（#118）

- 新增独立的简化显示开关：统一卡片分区，缩减空白和重复明细，保留费用、额度、预警颜色、刷新操作与悬停详情。
- 面板最多占视口高度的 38%，上限 320 像素；支持面板内滚动及键盘操作，今日金额固定在顶部。
- 更新首次提供「开启简化显示 / 保留当前显示」选择，保存后刷新和重启不再询问；失败可重试，新旧引导串行显示。
- 可在「设置 → 费用 → 显示」调整；关闭后恢复此前标准/紧凑两列偏好，沿用用户隐藏项。

### 验证

- 双时区全量回归通过，新增选择、保存失败、防重入、RPC、重启持久化、引导顺序与布局恢复回归。
- 在隔离 DSH 0.1.5-alpha.1 浏览器页面实测：示例多提供商配置从 626.19 像素降至 320 像素，英文、深色、窄栏、键盘滚动、悬停详情及设置切换通过。示例使用合成数据，详见[使用与验证说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.19/docs/sidebar-simple.md)。

## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.19/install.ps1 | iex
```

升级后重启 dsh web 并刷新页面，在首次提示中选择是否开启简化显示。
