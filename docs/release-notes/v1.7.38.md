## v1.7.38 — External usage sources

Issue [#181](https://github.com/Han-1413141/dsh-cost-meter/issues/181): another process using the same DeepSeek account can supply usage through an atomically replaced local JSON snapshot. Settings → Cost keeps DSH and each external source separate while showing combined today, month and all-time totals. Expanding a source shows its token buckets, calls, cost and recent daily records. Official balance reconciliation and the DSH budget widget remain based on DSH usage.

The [bilingual snapshot guide](../external-usage.md) documents daily summaries with exact USD cost and individual calls priced using the plugin's provider/model catalog at call time. The reader bounds file size and entry counts, rejects malformed data, and marks snapshots stale after 24 hours.

Install version 1.7.38 from npm or the pinned GitHub tag:

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.38
```
