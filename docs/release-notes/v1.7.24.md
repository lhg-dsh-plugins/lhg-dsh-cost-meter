## v1.7.24 更新

- 修复 [#139](https://github.com/Han-1413141/dsh-cost-meter/issues/139)：OpenCode Go 额度可发现官方 Go 路由实际配置的 `apiKeyEnv`，支持任意路由名；配置状态与查询来源同步。

- [#140](https://github.com/Han-1413141/dsh-cost-meter/issues/140) 使用的是 1.7.21，其搜索事件导致会话重启无法加载的问题已在 1.7.22 修复。请确认插件实际版本；已有受影响日志仍需按 [恢复说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.24/docs/session-history-recovery.md) 备份修复。
