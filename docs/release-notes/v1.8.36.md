## v1.8.36 — 旧会话金额修复、赠送余额对账与 DSH 0.2.1-rc.2

- 修复 [#300](https://github.com/Han-1413141/dsh-cost-meter/issues/300)：升级后升级前产生的老会话费用显示 ¥0 而 Token 正常。加载时回填的冻结汇率金额现在会随首次落盘持久化，跨进程合并与重复落盘不丢失、不重复；客户端在冻结金额缺失或为 0 而 USD 金额非 0 时回退到 USD 原值 × 当前汇率。USD 账本数据、历史金额与计价规则不变。
- 修复 [#302](https://github.com/Han-1413141/dsh-cost-meter/issues/302)：赠送余额部分到期/回收（充值余额未变、本地官方渠道费用远低于减量）不再误报为消费对账偏差，改为重置基准并给出一次性说明；本地费用能解释减量 1/4 以上或充值余额减少时仍按真实偏差提示。
- DSH 兼容：最低支持 DSH 0.2.0，适配目标为 npm `next` 的 **0.2.1-rc.2**；rc.2 真机记录见[宿主兼容验证](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.36/docs/host-compatibility.md#已验证宿主dsh-021rc22026-10-17)。
- 文档：补充 DSH 0.2.1-rc.x 宿主内置 pnpm 11.28.5 的 24 小时供应链策略导致插件安装/卸载失败的排障与绕行方案。[说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.36/docs/pnpm-supply-chain-policy.md)
- 升级方式：重跑新版 `install.ps1` 或插件市场更新，升级后完全重启 DSH。账本格式不变，不自动重算历史金额。

[完整更新说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.36/docs/update-notes-1.8.36.md)

### English

Fixes [#300](https://github.com/Han-1413141/dsh-cost-meter/issues/300): pre-upgrade sessions showed ¥0 after upgrading while token counts stayed correct. Backfilled frozen FX amounts are now persisted on the first flush and survive concurrent merges and repeated writes; the client falls back to the USD amount × current FX rate when the frozen fields are missing or zero with a nonzero USD amount. USD ledger data, historical amounts and pricing rules are unchanged.

Fixes [#302](https://github.com/Han-1413141/dsh-cost-meter/issues/302): a partially expired or reclaimed granted balance (with an unchanged top-up balance and local official-channel spend far below the decrease) no longer reports consumption drift; the baseline is reset with a one-time explanation, while genuine drift is still reported.

Minimum host is DSH 0.2.0; the adaptation target is npm `next` **0.2.1-rc.2** (see the [host compatibility record](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.36/docs/host-compatibility.md)). Also documents pnpm 11.28.5 supply-chain install/uninstall failures on DSH 0.2.1-rc.x and their workarounds ([policy note](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.8.36/docs/pnpm-supply-chain-policy.md#english)). Re-run the new `install.ps1` or update from the plugin market, then fully restart DSH.
