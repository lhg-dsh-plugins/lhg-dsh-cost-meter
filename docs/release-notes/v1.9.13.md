# v1.9.13 — 会话列表金额、额度显示与计费修复

- 新增 WorkBuddy 官方积分余额，读取本地登录文件，支持个人与企业账号；默认关闭。感谢 [@SternChiri](https://github.com/SternChiri) 在 [PR #341](https://github.com/Han-1413141/dsh-cost-meter/pull/341) 提供实现和测试，凭据与计费适配源自 [@corrinehu 的 dsh-workbuddy-connect](https://github.com/corrinehu/dsh-workbuddy-connect)，已保留 MIT 许可。

## English

Optional session-list amounts, readable host model names, CommandCode monthly usage, Codex quota progress and reset times, and corrected turn-cost currency forwarding. Ollama Cloud DeepSeek uses its own weekday 12:00–18:00 UTC peak calendar; existing recorded amounts are preserved unless explicitly recalculated.
