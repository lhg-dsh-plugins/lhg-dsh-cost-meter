## v1.8.15

- Merged [#240](https://github.com/Han-1413141/dsh-cost-meter/pull/240) by UNscientific-9, fixing [#239](https://github.com/Han-1413141/dsh-cost-meter/issues/239). Conversation Cost details now centers below the Desktop title bar, supports older Windows hosts and macOS clearance, and uses the full viewport in fullscreen. Border and padding fit within the width limit on narrow windows.
- Outdated client styles are replaced during hot reload. Dialog positioning remains available for skins to override; invalid host height variables retain a bounded, scrollable dialog.
- Automatic refresh preserves current statistics, conversation details and expanded turns. New usage, date boundaries and billing configuration refresh both overview and detail; a changing clock alone no longer triggers requests. Background failures show errors while retaining prior results, with retry controls in the detail views.
- Full local regression, 242 browser assertions and all 12 PR CI jobs passed. An additional check against the shipped client covered 54 layouts and state transitions. macOS geometry was tested using host variables in Chromium, without a native macOS Desktop run. Lossless bilingual dictionary packing keeps the main client at 261,470 bytes within the 256 KiB limit.

## Upgrade / 升级

Web Profile:

```powershell
dsh plugin --profile web add github:Han-1413141/dsh-cost-meter#v1.8.15
```

Restart `dsh web`, then reload the page. Desktop users should update the application's `desktop` Profile with its own CLI, then fully exit the application (including its tray process) and reopen it. See the [Desktop installation guide](../install-troubleshooting.md#desktop-安装与更新).

Web 用户更新后重启 `dsh web` 并刷新页面。桌面端使用应用内置 CLI 更新 `desktop` Profile，然后完全退出应用（包括托盘）再打开。
