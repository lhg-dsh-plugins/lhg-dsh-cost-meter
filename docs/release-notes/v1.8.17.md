## 模型选择菜单中的 OpenRouter 单价

响应 [#244 的后续建议](https://github.com/Han-1413141/dsh-cost-meter/issues/244#issuecomment-6075764881)，打开输入框旁的模型选择菜单，悬停 OpenRouter 模型，即可在 DSH 原生提示中查看：

- 输入、输出、缓存读取和缓存写入单价，单位为美元 / 百万 tokens。
- 上下文长度与最近成功更新时间。
- 查询失败或目录缺少模型价格的提示；失败时保留旧价格和时间。

菜单在前台打开时每分钟刷新；悬停和返回前台也会检查更新，两次请求至少间隔 15 秒。关闭菜单后停止价格请求。模型单价按提供商和完整 ID 匹配，免费版与付费版分别显示；原有模型选择操作保持不变，提示支持中英文。

仅查询 OpenRouter 公开目录，无需 API Key，不调用模型，不产生模型使用费用。设置 → 费用 → 价格中的完整搜索面板继续保留。详见[使用说明](../openrouter-prices.md#中文)。

## English

Hover an OpenRouter model in the composer model picker to see input, output and cache rates, context length and the last successful update time in DSH's native tooltip. Paid and `:free` variants use their exact model IDs. The menu refreshes every minute while visible, stops requesting prices when closed, and retains the last prices with a warning if a refresh fails. No API key or inference charges are involved.
