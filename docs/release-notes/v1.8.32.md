## v1.8.32 — Token Rhythm 余额

- 新增 **Token Rhythm 人民币可用余额**：在“费用 → 额度”添加卡片，保存官网登录 Cookie 后启用；可显示在侧栏、设置页或两处。
- 使用当前官网钱包接口的 `availableBalanceCny`，区分可用余额、冻结金额和历史消费；有效零余额正常显示，缺少金额或登录失效时提示错误。
- 复用余额缓存、请求合并、取消及 DSH 凭据库；重复打开设置不重查未过期结果，修改凭据后及时作废旧余额。仅执行余额查询。

### English

Adds Token Rhythm available CNY balance through the existing quota cards and credential store. Uses the current official wallet endpoint, reuses cached results, invalidates stale results on credential changes, and reports missing amounts or expired sessions. Configure it under Cost → Quotas → Add Token Rhythm balance. Synthetic responses and an unauthenticated endpoint check were used; no authenticated live account was tested. Fully restart DSH after updating.
