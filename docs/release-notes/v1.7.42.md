# v1.7.42 — 侧栏多插件布局修复

修复 [#192](https://github.com/Han-1413141/dsh-cost-meter/issues/192)：同时启用 dsh-cost-meter 和 dsh-context 时，费用卡片与「上下文洞察」按钮会争抢侧栏宽度，造成文字截断和按钮挤压。

- 展开侧栏时，费用区独占一行，其他插件按钮按可用宽度排列。
- 收起侧栏时，保留纵向图标布局；隐藏或停用费用区后自动恢复宿主布局。
- 移除手动移动 React DOM 和覆盖宿主内联样式的逻辑，避免动态启停时干扰其他插件。

验证使用 DSH 0.1.7-rc.2 与 dsh-context 的底部布局样式，覆盖 24 种布局和 10 次动态切换，共 282 项浏览器断言。v1.7.41 在相同用例中复现挤压，修复版和完整仓库测试通过。

