## v1.8.12

- Added the Bailian CLI console-login button from [#235](https://github.com/Han-1413141/dsh-cost-meter/pull/235). When quota queries report an authentication failure or status confirms missing console credentials, the Qwen card offers **Login**. Ordinary query/status errors remain retryable query failures.
- Login runs only after the button is clicked and opens the authorization browser on the DSH host. After completion, the plugin verifies console credentials and refreshes quota. Successful login and unavailable subscription quota are reported separately. Remote/headless hosts can use the documented manual CLI login.
- Concurrent login requests share one process. Source changes, hidden quota display and plugin unload cancel pending login. Child output is discarded, errors are classified and bilingual, and login/refresh share one client action state so messages and busy controls survive the transition.
- Fixed both host-generation client-registration checks by comparing registered methods with the server RPC list and exercising the login RPC through the real gateways. Added synthetic-credential subprocess and bilingual button regressions; the full local regression and the PR CI passed. Live account browser authorization was not performed.
- Lossless dictionary packing preserves all 529 Chinese and 529 English translations. The generated client is 261,488 bytes, within the 262,144-byte limit. The existing required **Other plugins & browser extensions** bug-report field remains in place.

Thanks to **WinterXMQ** for the login-button contribution.

- 合并并发登录；切换来源、关闭显示或卸载插件时取消进程。丢弃子进程原始输出，使用脱敏的双语错误；登录与刷新共用操作状态，切换后保留提示和忙碌控制。
- 修复两版宿主的客户端注册检查，逐项比对 RPC 方法并经真实网关调用登录接口。新增合成凭据子进程及双语按钮回归，本地完整回归和 PR CI 通过；未执行真实账号的浏览器授权。

## Upgrade / 升级

Web Profile:

```powershell
dsh plugin --profile web add github:Han-1413141/dsh-cost-meter#v1.8.12
```

Restart `dsh web`, then reload the page. Desktop users should update the application's `desktop` Profile with its own CLI, then fully exit the application (including its tray process) and reopen it. See the [Desktop installation guide](../install-troubleshooting.md#desktop-安装与更新).

Web 用户更新后重启 `dsh web` 并刷新页面。桌面端使用应用内置 CLI 更新 `desktop` Profile，然后完全退出应用（包括托盘）再打开。
