# v1.7.44 — 支持 DSH 0.2.0-rc.1

修复 [#195](https://github.com/Han-1413141/dsh-cost-meter/issues/195)：DSH 0.2.0-rc.1 安装插件时提示版本不兼容，已有插件也会在启动时被跳过。

原因是两个宿主 peer 的旧范围都在 `0.2.0-0` 之前结束。本版为两项依赖追加 `>=0.2.0-rc.1 <0.3.0-0`，保留原有 0.1 范围。正常安装即可，无需 `allow-version`。

已用官方 DSH 0.2.0-rc.1 完成安装包安装、Web 启动、宿主模块复用、费用 RPC、三次合成用量入账和完整回归。CI 新增该宿主的安装启动验证；会话测试同时适配 v3、v4 格式。验证没有发起付费模型请求。环境与范围见[兼容记录](../host-compatibility.md)。

## 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.44/install.ps1 | iex
```

也可运行 `dsh plugin --profile web add dsh-cost-meter@1.7.44`。升级后重启 DSH，Web 版同时刷新页面。
