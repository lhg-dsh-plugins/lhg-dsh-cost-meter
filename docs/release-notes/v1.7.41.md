# v1.7.41 — 用量与价格修复

- 官方余额对账计入有效外部快照的今日费用；快照超过 24 小时会暂停偏差提示。外部用量仍不写入 DSH 会话账本或预算。
- 侧边栏今日摘要可在显示设置中切换费用与 Token 用量，适用于普通、简化和预算视图。
- 小米 MiMo V2.6 三型号加入官方人民币档位。选择 CNY 价格时按人民币报价计算，再依显示汇率折算到账本美元；没有人民币档位的第三方模型仍按美元价计算。
- 模型名自动匹配只接受同名及日期、版本、上下文长度后缀，避免新变体沿用旧型号价格。OpenCode Go 未收录的 UltraSpeed 保持未定价。
- 模型统计页可按任意 `provider:model` 指定 Plan 或 API 类别，修改后同步更新历史 API 费用分类。

社区贡献 PR #188 已合并。已运行完整仓库验证与 `npm pack --dry-run`。
