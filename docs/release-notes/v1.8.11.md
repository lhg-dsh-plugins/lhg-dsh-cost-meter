## v1.8.11

- Cost Overview no longer mounts password inputs automatically. Click **Edit credential** to open a masked editor in its own form, with `new-password` and password-manager ignore hints. Cancel, successful Save and Clear remove the editor and erase its draft; duplicate Save/Clear requests are blocked.
- Added [sidebar search recovery instructions](../session-sidebar-recovery.md) for [#232](https://github.com/Han-1413141/dsh-cost-meter/issues/232). If an existing tab shows loading placeholders followed by “No matching sessions”, close Settings, reveal **Search sessions**, and inspect any unexpected query. Use **Clear search** or Escape in the focused search input; reload the page if needed.
- Search recovery and credential lifecycle checks pass on DSH 0.1.7-rc.2 and 0.2.0-rc.2. The search tests preserve 18 synthetic workspaces, original message files and a 78,000-call ledger. The saved-login pairing test is an explicit model, not a native browser reproduction. The reporter's normal-tab trigger remains unconfirmed, and #232 stays open for their recovery and upgrade results.
- Lossless phrase packing preserves all 527 Chinese and 527 English translations and keeps the generated client within the 262,144-byte limit. Bug reports now request other plugin package names, versions, relevant configuration and browser extensions.

## Upgrade / 升级

Web Profile:

```powershell
dsh plugin --profile web add github:Han-1413141/dsh-cost-meter#v1.8.11
```

Restart `dsh web` after updating, then reload the browser page. For Desktop, use the application's own CLI with the `desktop` Profile as described in the [Desktop installation guide](../install-troubleshooting.md#desktop-安装与更新), then fully exit the application (including its tray process) and reopen it.

Web 用户更新后重启 `dsh web` 并刷新浏览器页面。桌面端使用[安装说明](../install-troubleshooting.md#desktop-安装与更新)中的应用内置 CLI 更新 `desktop` Profile，然后完全退出应用（包括托盘）再打开。
