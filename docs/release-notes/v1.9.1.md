## v1.9.1 — 皮肤半透明透出修复与性能优化

- 修复皮肤插件把主题别名调成半透明后，插件浮层与弹窗（统计明细弹窗、额度引导、峰谷提醒、费用明细、组合浮层等）透出后方页面内容的问题：改为「本地不透明基底 + 皮肤色渐变叠层」合成，保留皮肤色调，默认主题视觉不变。
- 记账不再每笔重建整份价格历史快照（原占单笔耗时 99.8%）：1000 笔连续记账 1308ms → 93ms。
- 账本落盘合并去掉冗余深拷贝：普通 flush 约 40ms → 30ms，账本内容与语义哈希不变。
- 统计页渲染缓存键改用 `pricesRev`（2.55ms → 0.015ms），设置页自动保存的逐键比较增加引用短路。
- 新增皮肤遮挡静态断言与真实浏览器 Dream Skin 回归；全量 `node test/verify.mjs` 通过。无配置/账本格式变化，无需手动迁移。

[完整更新说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.9.1/docs/update-notes-1.9.1.md)

升级：`dsh plugin --profile desktop add dsh-cost-meter@1.9.1`，或 `irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.9.1/install.ps1 | iex`，随后重启 DSH。

### English

- Fixed translucent skin plugins leaking page content through plugin overlays and dialogs (stat dialog, quota guide, peak alert, fee dialog, combo popover, etc.): overlays now composite an opaque local base with a skin-tint gradient, keeping the skin hue with no visual change on the default theme.
- Accounting no longer rebuilds the full price-history snapshot per entry (previously 99.8% of per-entry cost): 1000 consecutive entries 1308ms → 93ms.
- Ledger flush merge drops redundant deep clones: a normal flush drops from ~40ms to ~30ms with identical content and semantic hash.
- The statistics render cache key now uses `pricesRev` (2.55ms → 0.015ms), and settings auto-save diffing short-circuits unchanged entries.
- New skin-occlusion static assertions and a real-browser Dream Skin regression; the full `node test/verify.mjs` suite passes. No configuration or ledger schema changes and no manual migration.
