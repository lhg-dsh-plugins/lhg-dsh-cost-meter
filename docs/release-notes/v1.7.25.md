## v1.7.25 更新

- **#142 侧栏按模型花费**：新增可折叠卡片，默认关闭、首次收起；支持今日 / 近 90 天、Top-N（1–10，默认 5）、其它模型汇总、占比条及可选输入/缓存/输出 Token。复用设置页分模型账本，按现有 API / Plan 展示口径与币种计算。
- 显示设置可配置卡片位置、总额/Top-1 摘要、默认展开、展开记忆、10–60 秒快照刷新和 Top-1 dock 角标；简化侧栏显示摘要，rail 显示图标并通过悬停查看总额。长模型名省略，金额保留。
- **#143 统一额度卡片**：整合 @UNscientific-9 的实现，保留原始提交；网关、Go、10 家 Coding Plan、自定义余额使用同级卡片，启用项优先，各组保持网关 → Go → Coding Plan → 自定义余额的顺序。标题左侧开关、右侧刷新，逐卡展开和独立刷新；展开与排序不落盘。
- 补齐 Go 卡片内配置，保留网关 4 条 / 自定义余额 8 条上限和重复条目。重排及删除保留对应条目的编辑状态；未保存启用或删除变更时刷新受控，防止错误下标查询。
- 增加模型金额、90 天边界、旧账本、双币种、strict codec、持久化、展开记忆、卡片身份、并发刷新、共享快照轮询与插槽门控回归；完整验证通过，客户端仍低于 262144 字节上限。

使用入口与配置含义见 [模型花费卡片说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.25/docs/model-cost-card.md)。

## Upgrade / 升级

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.25/install.ps1 | iex
```

完全退出并重启 DSH，再刷新 Web UI。在「设置 → 费用 → 显示」启用模型花费卡片。额度卡片布局会自动更新。

**English:** Adds an optional collapsible per-model sidebar card with Top-N / Other totals, shares, tokens, Today / Last 90 days, expansion preferences and a Top-1 dock chip. Unifies quota settings into individually expandable cards with enabled entries first. Includes the original contribution from @UNscientific-9, corrected default ordering, Go settings, independent refresh and stable entry identity. Quota configuration and RPC signatures remain unchanged; model-card preferences use a separate optional configuration object.
