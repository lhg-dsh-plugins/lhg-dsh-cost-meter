# v1.8.16 — OpenRouter model prices / 模型价格查询

Settings → Cost → Prices now includes a searchable OpenRouter public price catalog. It shows input/output/cache rates, context length, price changes and official model links. It refreshes on opening, every minute while visible, and on returning to the foreground. Failed queries keep the last successful prices and timestamp.

The lookup needs no API key and sends no inference requests, so it incurs no model usage charges. It does not change your configured billing prices or historical ledger. Routing, promotions, tiers and additional fees remain subject to OpenRouter's official pricing.

设置 → 费用 → 价格新增 OpenRouter 模型价格查询，支持搜索、排序、缓存单价、上下文长度、价格变动提示和官方模型链接。前台每分钟刷新，失败保留上次成功价格与时间。公开目录查询无需 API Key，不产生模型调用费用，不修改计费配置和历史账本。界面沿用 DSH 明暗主题，支持中英文与窄窗口滚动。

This release also includes the build-script and test-fixture security fixes merged in #243. 本版同时包含 #243 已合入的构建脚本和测试页面安全修复。

## Upgrade / 升级

```powershell

```

Use the CLI and Profile of your running DSH installation. Desktop users should use the application's bundled CLI and `desktop` Profile. Restart DSH and reload its page after updating.

请使用当前 DSH 安装对应的 CLI 和 Profile。桌面版使用其内置 CLI 与 `desktop` Profile。更新后重启 DSH 并刷新页面。
