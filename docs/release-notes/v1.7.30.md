## v1.7.30 更新

- 合入 [@GnaneshKunal 的 PR #156](https://github.com/Han-1413141/dsh-cost-meter/pull/156)：OpenRouter 四模型离线快照与公开目录 token 价格，启动、手动同步和每小时刷新。
- 补齐定向回填与自定义价格保护：只补算 OpenRouter 零费用桶，保留已有费用、其他厂商和显式价格映射；自动刷新识别手改价格，重启后仍保留。
- 完整 id 匹配，隔离免费变体；并发请求合并，总超时覆盖响应体，失败保留本地价格，卸载取消并阻止迟到写入。DeepSeek 同步失败时，OpenRouter 成功更新的状态也会返回客户端。
- 增加真实服务、启动/定时刷新、生命周期、历史范围、持久化、解析和双端 codec 回归。

详见[定价说明与适用范围](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.30/docs/openrouter-pricing.md)。

## Upgrade / 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.30
```

或使用固定版本安装脚本：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.30/install.ps1 | iex
```

完成更新后重新运行 dsh web 并刷新浏览器。

**English:** Adds OpenRouter token reference prices and automatic catalog refresh from PR #156. Scoped zero-cost backfill preserves existing charges and other providers; persisted fingerprints protect custom prices. Includes exact variant matching, concurrent-request sharing, failure fallback, cancellation and regression coverage.
