## 自定义渠道的套餐归属

修复讨论 #164：自定义渠道已标为 Plan，却未关联到具体套餐，导致本地周期用量显示为零。

在「设置 → 费用 → 用量 → 按模型统计 → 计费方式」中，为模型选择具体套餐即可。支持所有已接入套餐，手动选择优先；自动模式识别渠道或模型 ID 中明确的厂商名称与套餐特征，遇到多个厂商时不自动归属。

历史日统计、近期窗口统计、千问和 SCNet 本地 Credits 使用同一归属。近期 48 小时从已有会话日志恢复，核对完整后才写入，不重复增加调用次数或费用；普通刷新额度不扫描日志。

本版还包含微信交流群入口：README 顶部链接到后方二维码，费用设置中的首次提示可以关闭，关闭后入口移至页面底部。

升级后重启 DSH，客户端刷新页面即可。
