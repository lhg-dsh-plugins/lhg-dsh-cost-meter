## v1.7.27 更新

- 修复 #149：DSH 源码版要求 strict codec 提供 `create()`，插件现在在 Host 和 Client 两端同时提供 `schema` 与 `create()`，保留旧宿主兼容性和原有校验。
- 增加真实源码宿主的 loader、registry、前后端 RPC 回归，覆盖缺少工厂的启动失败、合法参数、可选参数及非法输入拦截。npm 0.1.6-alpha.1 与同版本号的源码版契约不同，CI 分别验证。
- 根据 #140 的后续反馈，补充手工备份目录和 Zstandard 头帧约束。工具自带的相邻备份使用非规范文件名，可被宿主忽略；1.7.22+ 搜索明细仍保存在插件独立文件中，不再追加宿主事件。

旧日志的备份与恢复步骤见[恢复指南](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.27/docs/session-history-recovery.md)。升级后请完全退出并重启 DSH。

### English

Fixes #149 by providing both `schema` and `create()` on every host and client strict codec. CI now checks an actual pinned DSH source loader, registry and both RPC gateways, alongside the released host. The session recovery guide clarifies manual backup placement, independent Zstandard header frames and the separate native-search storage introduced in 1.7.22. Restart DSH after updating.
