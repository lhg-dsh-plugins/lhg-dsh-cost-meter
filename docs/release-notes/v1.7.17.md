# v1.7.17：SCNet 外部快照与项目审查修复

SCNet 可读取账本目录的 `scnet_official.json`，优先展示外部控制台快照中的已用 Credits 和总额度，覆盖本地账本看不到的其他工具用量。保留小数和采集时间，中英文明确标注来源。

整合并补齐 PR #114：严格区分采集时间与重置时间；缺失、无效、超过 16 KiB、采集超过 24 小时或已跨周期时回退本地估算。有界异步读取不会把损坏文件扩散为整个费用面板失败，也不会改写账本。

外部采集器需另行提供，插件不自动登录/采集控制台。文件格式、更新和账号切换说明见 [接入文档](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.17/docs/scnet-official-snapshot.md)。

本次审查同时修复 SCNet 本地估算跨渠道误计、自定义余额空白误判、超大响应读取、调用方取消后仍重试，以及混合凭据模板脱敏。SCNet 本地估算只统计已识别的 SCNet 订阅渠道，显式 API 分类除外；其他渠道同名模型不会再被计入。

整合 PR #117：移除额度行多余的浏览器原生提示，侧栏统一使用卡片 Tooltip 展示完整窗口、额度与重置倒计时，避免两层提示互相遮挡。

双时区回归与 DSH `0.1.2-rc.1`、`0.1.3-alpha.2`、`0.1.5-alpha.1` 安装包加载通过，当前 alpha.2 本地链接的费用页面与合成用量验证通过。已补入 `0.1.5-alpha.1` 精确兼容声明及其宿主 peer 范围。测试均使用隔离数据目录；详见[兼容记录](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.17/docs/host-compatibility.md)和[审查记录](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.17/docs/project-audit-v1.7.17.md)。
