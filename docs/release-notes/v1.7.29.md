## v1.7.29 更新

- **#154 市场热安装**：修复安装后“账本不可用”，重启 DSH 才恢复的问题。文件入口现在会补齐费用 RPC 清单，注册随插件卸载清理，支持注册服务晚到和重新挂载。
- 首屏读取失败自动退避重试；费用页显示具体错误和“刷新”按钮。成功后恢复正常轮询，隐藏页面暂停轮询，卸载后的迟到响应不再更新快照。
- 增加报告版本 DSH 0.1.5-rc.1 的真实宿主回归，覆盖失败对照、热安装、正常启动、服务晚到和卸载重装；保留完整回归及 Windows/Linux 安装检查。

详见[热安装说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.29/docs/market-hot-install.md)。

## Upgrade / 升级

```sh
dsh plugin --profile web add dsh-cost-meter@1.7.29
```

或使用固定版本安装脚本：

```powershell
irm https://raw.githubusercontent.com/Han-1413141/dsh-cost-meter/v1.7.29/install.ps1 | iex
```

已运行的旧代码需要先完成更新；若更新器提示重启，请重新运行 `dsh web`，再刷新浏览器。

**English:** Fixes missing ledger RPC registration after a marketplace hot install. Initial reads recover with bounded backoff, and the empty state exposes the error and a Refresh button. Includes real host lifecycle/RPC regressions and client retry/cleanup coverage.
