## v1.9.0 — 订阅插件与 SQLite 会话存储兼容、手机端适配与 OpenDesign preflight 回退

- 新增 **Codex 订阅插件兼容**（dsh-codex-subscription）：自动检测并把这部分用量归为 Plan 订阅额度；首次检测时弹出一次性「兼容修复」提示，可关闭、可随时在「设置 → 费用 → Codex」重新操作；历史 Codex 计费仅在用户确认后重算（幂等）。
- 新增 **ChatGPT 订阅插件兼容**（@eddyskywalker/dsh-chatgpt-subscription）：识别 9 条订阅线路（codex-chatgpt / kimi-code / command-code / workbuddy-subscription / claude-subscription / minimax-code / antigravity / glm-coding-plan / step-code），自动把「自动」分类的厂商归为 Plan；新增 WorkBuddy / Antigravity / StepFun 三个 Plan 厂商。
- 新增 **better-session SQLite 会话存储兼容**（@morlay/better-session / @morlay/session-rdb）：RDB 模式不再产生 JSONL 时，历史回填、旧账本导入、历史重定价、小时桶修复、fork 清洗、逐会话费用/轨迹/调用详情仍可用；JSONL 路径行为不变；修正 RDB 空扫描误消费一次性迁移标记；启动日志显示会话存储后端，修复 CLI 检测到 RDB 时明确提示并退出码 2。[说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.9.0/docs/better-session.md)
- **dsh-pocket 手机端适配**：设置页、侧栏卡片、额度横条、预算框、统计/显示/定价/OpenRouter/社区/Codex 面板全部适配 ≤1023px 窄屏与移动布局；桌面布局不变。
- **OpenDesign 额度查询修复（#274）**：Control Key 在主端点 401/403 时保守回退 `/billing/preflight`，窗口查询恢复可用；窗口与钱包读取独立并行、支持部分降级，错误区分鉴权失败/无订阅/响应无效/网络失败；文档补充端点权限与 `workspaceId` 取值。[说明](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.9.0/docs/opendesign-billing.md)
- 感谢 [#274](https://github.com/Han-1413141/dsh-cost-meter/issues/274) 的 [@playgithub](https://github.com/Han-1413141/dsh-cost-meter/issues/274#issuecomment-6215322540)（需求与复现）、[@codeforker654](https://github.com/Han-1413141/dsh-cost-meter/issues/274#issuecomment-6236228870)（401 复现报告）、[@yunjuanhuakai](https://github.com/Han-1413141/dsh-cost-meter/issues/274#issuecomment-6236591566)（`/billing/preflight` 端点发现与回执样例）。
- 升级方式：重跑新版 `install.ps1` 或插件市场更新，升级后完全重启 DSH。账本格式不变；除主动确认的历史 Codex 归类外不自动重算历史金额。

### English

- **Codex subscription plugin compatibility** (dsh-codex-subscription): detected automatically and classified as Plan quota. A one-time dismissible "Compatibility fix" prompt appears on first detection and can be reopened from Settings → Cost → Codex; historical Codex billing is only recomputed after confirmation (idempotent).
- **ChatGPT subscription plugin compatibility** (@eddyskywalker/dsh-chatgpt-subscription): recognizes nine subscription routes (codex-chatgpt / kimi-code / command-code / workbuddy-subscription / claude-subscription / minimax-code / antigravity / glm-coding-plan / step-code) and auto-classifies "auto" vendors as Plan; adds WorkBuddy / Antigravity / StepFun plan vendors.
- **better-session SQLite session storage compatibility** (@morlay/better-session / @morlay/session-rdb): when RDB storage replaces JSONL, historical backfill, legacy import, history repricing, hour-bucket repair, fork cleanup and per-session cost/trajectory/call inspection keep working. The JSONL path is unchanged; empty RDB scans no longer consume one-time migration markers; startup logs the storage backend and the repair CLI exits with code 2 instead of pretending to repair. [Guide](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.9.0/docs/better-session.md)
- **dsh-pocket mobile layout**: settings, sidebar cards, quota strip, budget box and the statistics/display/pricing/OpenRouter/community/Codex panels adapt to ≤1023px and mobile layouts; desktop layout is unchanged.
- **OpenDesign quota fix (#274)**: on 401/403 from the primary endpoint the plugin conservatively falls back to `/billing/preflight`, restoring window queries. Window and wallet reads are independent with partial degradation, and errors distinguish auth failure / no subscription / invalid response / network failure. Docs cover endpoint permissions and `workspaceId`. [Details](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.9.0/docs/opendesign-billing.md)
- Thanks to [@playgithub](https://github.com/Han-1413141/dsh-cost-meter/issues/274#issuecomment-6215322540) (request and reproduction), [@codeforker654](https://github.com/Han-1413141/dsh-cost-meter/issues/274#issuecomment-6236228870) (401 repro report) and [@yunjuanhuakai](https://github.com/Han-1413141/dsh-cost-meter/issues/274#issuecomment-6236591566) (preflight endpoint discovery and sample responses) in [#274](https://github.com/Han-1413141/dsh-cost-meter/issues/274).
- Upgrade: re-run the new `install.ps1` or update from the plugin marketplace, then fully restart DSH. The ledger format is unchanged; historical amounts are not recalculated automatically except for the confirmed historical Codex reclassification.
