## v1.7.31

### English

- **#157:** explain USD-to-CNY display conversion and offer official CNY price selection in Settings → Cost → Prices. Select CNY, wait for auto-save, then sync prices. No automatic currency/rate change; the existing sync flow handles history recalculation. [Billing currency guide](https://github.com/Han-1413141/dsh-cost-meter/blob/v1.7.31/docs/billing-currency.md#english).
- **#158:** document the pnpm prerequisite for Plugin Hub and npm-name installs, with macOS/Linux PATH and process-restart instructions. On Node.js ≥ 22.13, run `npm install -g pnpm@11.21.0`, verify `pnpm --version`, and retry from the same terminal. The reporter's machine needs this environment fix; the plugin cannot repair a package manager before installation.
- **#159:** show MiniMax weekly **∞** when the API explicitly reports unlimited usage. Display the 5h reset countdown on the expanded sidebar card and refresh it locally every minute. Missing reset data stays unknown.
- **#160:** show cache hit rate before Input in the composer footer: cache reads divided by all input tokens, including cache writes. API/Plan and subagent amounts keep their existing behavior.
