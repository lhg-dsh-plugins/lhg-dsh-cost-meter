# 1.7.17 项目审查与验证记录

日期：2026-09-09。范围：SCNet 外部快照整合、费用与额度口径、自定义余额/网关请求边界、凭据处理、构建及 DSH 加载。

## 已修复的问题

| 问题 | 修复后的行为 | 回归证据 |
| --- | --- | --- |
| SCNet 按模型名跨提供商汇总，其他渠道同名模型被误计 | 仅收录 SCNet 订阅 ID，应用显式 Plan/API 分类；前后端别名一致，历史分类幂等重算，原始用量/等值金额保留 | `test/project-audit.mjs` 真实服务四渠道、分类覆盖及历史迁移 |
| 空白/非十进制金额被强制转换为数字 | 主余额无效时失败；无效可选预算/支出为空；正常数字与十进制字符串保留 | 空白、布尔值、null、十六进制、正常小数回归 |
| 自定义余额无响应上限，网关在全部读取后才检查长度 | 标准 Node Response 按实际流字节数限制；超限取消；自定义余额 HTTP 错误也释放未读响应体 | 谎报长度的流、取消标志及 HTTP 错误路径 |
| 调用方已经取消仍可能重试或等待退避 | 请求前检查取消，失败后优先传回取消原因，退避监听取消 | 已取消不发请求；退避中取消只尝试一次 |
| 混合模板可能让静态密钥绕过脱敏 | 检查占位符以外的静态内容；混合密钥模板保留待手动处理，阻止持久化和浏览器回传；不创建无法展开的嵌套凭据 | 纯引用、混合模板、脱敏及凭据库写入次数断言 |
| 并发回归使用相同临时目录 | 每次全量测试使用独立根目录，结束时只清理自己的数据 | Asia/Shanghai 与 UTC 同时运行并通过 |

PR #114 的外部快照另有严格数字与时间契约、16 KiB 有界异步读取、24 小时/周期有效期及异常回退。`test/scnet-snapshot.mjs` 检查真实服务优先级、小数、双语、采集/重置时间、刷新、开关并发和账本隔离，见[接入文档](scnet-official-snapshot.md)。

## 验证结果

- 本地完整回归在 `TZ=Asia/Shanghai` 和 `TZ=UTC` 下均以退出码 0 结束；最后补充的 HTTP 错误响应释放路径通过独立审查回归。远端安装工作流对待合并提交运行 Windows/Linux 回归及构建一致性检查。
- 整合 PR #117 后重新构建的客户端为 253,896 字节，小于商店单文件 262,144 字节上限；构建产物与源码同步。
- `pnpm audit --prod --json` 返回各级已知漏洞 0，口径为本包 1 个生产依赖；不包含宿主、开发依赖或未知漏洞。
- DSH 三版安装包（`0.1.2-rc.1`、`0.1.3-alpha.2`、`0.1.5-alpha.1`）、当前 alpha.2 本地链接、真实隔离服务计费、快照回退、Web 页面及卸载数据保留结果见[兼容记录](host-compatibility.md)。所有调用数与快照值都是测试合成数据。

## 边界

这是代码审查、自动回归和隔离环境加载验证，不是对所有缺陷不存在的保证。未验证真实账号的官方账单、SCNet 采集器、未上报宿主 usage 的第三方调用或 DSH Desktop 全部功能。有效外部快照只覆盖额度显示；本地 JSON 不能证明账号归属或官方实时性。

日常 Web Profile 的本地链接方式保持不变。代码更新后需重新启动日常 DSH 并刷新页面，才能让已运行的进程使用新代码；本次测试没有改写日常账本或第三方插件配置。
